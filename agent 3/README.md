# 🧠 AI Code Organizer Agent

This project allows you to automatically organize and save code generated by a Language Model (LLM) into structured folders like `/html`, `/css`, `/js`, and `/assets`, similar to platforms like [bolt.dev](https://bolt.dev). You can run this fully offline and open-source with no paid APIs required.

## 📖 Project Overview

**Goal**: Create an AI Agent that takes raw code output from an LLM and:

- Detects file types (HTML, CSS, JS, etc.)
- Extracts or infers file names
- Organizes code into proper folders
- Writes them as real files on disk
- Optionally initializes a Git repo
- Optionally zips the full folder for easy download

### 🔓 Fully Open Source

- **License**: MIT (free to use, modify, and distribute)
- **No paid APIs**: 100% offline processing, no OpenAI or cloud required (optional GitHub AI integration available)
- **Extensible**: Modular design to plug in new file types or logic

### 🔧 Ideal Use Cases

- Turn LLM-generated websites into runnable projects
- Frontend prototyping tools
- Online editors and code exporters
- Educational sandboxes and student tools

## ✅ Features

- ✅ Parse code blocks (HTML, CSS, JS, etc.) from LLM output
- ✅ Auto-organize files into folders
- ✅ Extract or infer filenames from comments
- ✅ Create a Git repo (optional)

- ✅ Fully offline and open source (MIT License)

## 💻 Usage

### Basic Usage

```python
from code_organizer import CodeOrganizer

# Initialize the organizer
organizer = CodeOrganizer(output_dir="my_organized_code")

# Parse LLM output from a file
with open("llm_output.txt", "r") as f:
    llm_output = f.read()

# Extract code blocks
extracted_files = organizer.parse_llm_output(llm_output)

# Organize the files
organizer.organize_files()

# (Optional) Initialize a Git repository
organizer.initialize_git_repo()

# (Optional) Create a ZIP archive
organizer.create_zip_archive()

# Get a summary of the organized code
summary = organizer.get_summary()
print(summary)
```

### Using a Predefined File Structure

```python
from code_organizer import CodeOrganizer

# Initialize the organizer
organizer = CodeOrganizer(output_dir="my_organized_code")

# Load a file structure from a JSON file
organizer.load_file_structure_from_file("file_structure.json")

# Parse LLM output from a file
with open("llm_output.txt", "r") as f:
    llm_output = f.read()

# Extract code blocks and organize the files
organizer.parse_llm_output(llm_output)
organizer.organize_files()
```

### Using GitHub AI Integration

```python
from code_organizer_enhanced import GitHubAI, CodeOrganizer

# Initialize GitHub AI
github_ai = GitHubAI()

# Generate code with a prompt
prompt = "Create a simple personal portfolio website with HTML, CSS, and JavaScript"
generated_code = github_ai.generate_code(prompt)

# Initialize the organizer
organizer = CodeOrganizer(output_dir="ai_generated_website")

# Extract code blocks and organize the files
organizer.parse_llm_output(generated_code)
organizer.organize_files()
```

### Command Line Interface

```bash
# Process LLM output from a file
python code_organizer.py --llm-output llm_output.txt --output-dir my_website --git --zip

# Use a predefined file structure
python code_organizer.py --llm-output llm_output.txt --structure file_structure.json --output-dir my_website

# Generate code with GitHub AI and organize it
python code_organizer_enhanced.py --generate --prompt "Create a personal portfolio website" --output-dir my_portfolio
```

## 📁 File Structure Format

The file structure should be provided as a JSON file with the following format:

```json
{
  "html/index.html": {
    "type": "file",
    "description": "Main HTML file"
  },
  "css/styles.css": {
    "type": "file",
    "description": "Main CSS file"
  },
  "js/script.js": {
    "type": "file",
    "description": "Main JavaScript file"
  },
  "assets": {
    "description": "Directory for assets"
  },
  "assets/images": {
    "description": "Directory for image assets"
  }
}
```

### Markdown File Structure Format

Alternatively, you can use a Markdown format for the file structure, which may be more readable:

```markdown
# Website Project Structure

## html

- index.html (Main HTML file)
- about.html (About page)
- contact.html (Contact page)

## css

- styles.css (Main CSS styles)
- responsive.css (Responsive design styles)

## js

- script.js (Main JavaScript file)
- utils.js (Utility functions)

## assets

- README.md (Assets folder readme)

## assets/images

- logo.png (Site logo)
- hero.jpg (Hero image)
```

The markdown format has several advantages:
1. More human-readable
2. Easier to edit and maintain
3. Support for nested directories (like `assets/images`)
4. More intuitive for non-technical users

To use a markdown file structure, simply specify the `.md` file when running the tool:

```bash
python code_organizer.py --llm-output code_output.txt --structure my_structure.md --output-dir website
```

## 🔄 How It Works

1. **Code Extraction**: The `parse_llm_output` method parses the LLM output to extract code blocks and their file types.
2. **File Organization**: The `organize_files` method creates directories and writes files according to the extracted code and file structure.
3. **Optional Features**: Initialize a Git repository and create a ZIP archive for easy sharing.

## 🔧 Advanced Configuration

### Using Different File Type Detection

You can extend the `infer_file_type` method to support additional file types:

```python
def infer_file_type(self, content: str) -> str:
    # Add your own file type detection logic here
    if re.search(r'<\?php', content):
        return "php"

    # Default to the base implementation
    return super().infer_file_type(content)
```

### Custom File Organization

You can override the `organize_files` method to implement custom file organization logic:

```python
def organize_files(self) -> None:
    # Implement your custom file organization logic here
    # ...

    # Call the base implementation for standard organization
    super().organize_files()
```
